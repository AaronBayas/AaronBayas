## 📌 Proyectos destacados

💻 **Batalla Trivial**
Aplicación web de preguntas y respuestas en tiempo real, con chat en vivo entre los participantes. Desarrollada con React y TypeScript.

📖 **CUENTIA**
Aplicación web dirigida a maestros de educación básica para crear cuentos personalizados con Inteligencia Artificial, adaptados a cada niño.

🌐 **Aplicación web de clasificación de residuos**
