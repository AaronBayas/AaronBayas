## Arquitectura y Caracteristicas del Portafolio Web

Este proyecto de portafolio web ha sido concebido y construido bajo estandares rigurosos de desarrollo web profesional, estructurado como una **Single Page Application (SPA)** nativa y documentada.

```
Portafolio/
|-- index.html                 # Punto de entrada de la Single Page Application (SPA)
|-- css/
|   |-- variables.css          # Design Tokens (Colores, tipografia, radios, sombras, espaciado)
|   `-- styles.css             # Estilos globales, layouts con Grid/Flexbox y media queries
|-- js/
|   `-- main.js                # Logica del cliente, observadores, modales y validacion reactiva
|-- media/                     # Recursos graficos optimizados y capturas del sistema
|   |-- Foto personal.jpg
|   |-- iconopag.png
|   |-- robot2.png
|   |-- logo.png
|   |-- giospro.png
|   |-- medilife.png
|   |-- bike.png
|   `-- capturas-...
|-- README.md                  # Documentacion academica interna
`-- READMEPORTAFOLIO.md        # Documentacion tecnica profesional para perfil de GitHub
```

### 1. Sistema de Diseno Centralizado (Design System)
- **Tokens CSS Custom Properties:** Arquitectura de variables globales distribuidas en tokens semanticos (`--color-primary`, `--color-secondary`, `--color-accent`, `--color-bg`, `--color-surface`, `--color-text`, `--color-text-muted`, `--color-success`, `--color-error`, `--color-warning`).
- **Escala de Espaciado Modular:** Jerarquia estricta desde `--space-2xs` (0.125rem) hasta `--space-5xl` (8rem) para garantizar consistencia ritmica en el layout.
- **Tipografia Profesional:** Uso coordinado de las familias tipograficas de Google Fonts:
  - **Outfit:** Encabezados, titulos de tarjetas y marca personal (pesos 600, 700 y 800).
  - **Inter:** Cuerpo de texto, parrafos, etiquetas y controles de formularios (pesos 400, 500, 600 y 700).
- **Componentes Atomicos y Reutilizables:** Estandarizacion de botones (`.btn--primary`, `.btn--secondary`, variaciones de tamano), tarjetas de proyectos, insignias tecnologicas (`.tech-tag`, `.skill-badge`), controles de formulario e indicadores de nivel con metricas porcentuales.

### 2. Gestion de Estado y Tema (Dark / Light Mode)
- **Persistencia en Almacenamiento Local:** Integracion con la API nativa de `localStorage` para recordar la preferencia de visualizacion del usuario entre sesiones.
- **Transicion Libre de Parpadeo:** Conmutacion suave de variables de color de fondo y superficie mediante manipulacion de clases en el elemento raiz del DOM.
- **Accesibilidad Visual:** Ratio de contraste verificado bajo estandares WCAG tanto en modo claro como en modo oscuro.

### 3. Logica de Filtrado Reactivo de Proyectos
- **Filtrado en Tiempo Real sin Dependencias:** Algoritmo en JavaScript Vanilla que lee atributos de datos (`data-techs`) en el arbol DOM y sincroniza el renderizado mediante transiciones CSS animadas (`fade-in-up`).
- **Categorizacion Multitecnologica:** Permite segmentar proyectos desarrollados con React, TypeScript, Python, PostgreSQL o prototipados en Figma con respuesta inmediata al usuario.

### 4. Sistema Centralizado de Modales Informativos
- **Carga Dinamica de Metadatos:** Inyeccion de informacion en tiempo de ejecucion (titulo, descripcion, problema resuelto, tags de tecnologia, capturas de pantalla, enlace a repositorio y enlace a demo en produccion).
- **Control de Foco y Accesibilidad:** Implementacion de focus trap para navegacion mediante teclado, soporte para tecla `Escape`, control de bloqueo del scroll del documento (`overflow: hidden`) y compatibilidad con lectores de pantalla a traves de atributos `role="dialog"`, `aria-modal="true"` y `aria-labelledby`.

### 5. Validacion Avanzada de Formularios del Lado del Cliente
- **Evaluacion en Tiempo Real:** Deteccion automatica de eventos `input`, `blur` y `submit` con validacion semantica de expresiones regulares para correos electronicos y umbrales de longitud minima para nombre y mensaje.
- **Estados Visuales Semanticos:** Clases dinamicas de exito (`.form-input.success`) y error (`.form-input.error`) con mensajes de advertencia vinculados mediante `role="alert"`.

### 6. Animaciones de Rendimiento y Scroll Inteligente
- **API Intersection Observer:** Efectos de aparicion gradual (`reveal`, `reveal-left`, `reveal-right`, `reveal-scale`) activados de forma asincrona unicamente cuando los elementos entran en el viewport, evitando bloqueos en el hilo principal de ejecucion.
- **Navegacion Fluida y Scroll Spy:** Deteccion de posicion de desplazamiento con observador de eventos pasivos (`{ passive: true }`) para aplicar efectos de glassmorphism a la barra de navegacion superior y resaltar dinamicamente la seccion activa.
- **Boton Scroll-To-Top:** Componente de retorno rapido con transicion suave (`scroll-behavior: smooth`).

## Buenas Practicas y Filosofia de Ingenieria

1. **Clean Code y Modularidad:** Separacion estricta de responsabilidades (SoC) entre la estructura semantica (HTML5), la capa de presentacion y tokens (CSS3) y la logica de interaccion (JavaScript modular).
2. **Control de Versiones Semantico:** Flujo de trabajo con Git basado en mensajes de confirmacion convencionales (`init:`, `feat:`, `style:`, `docs:`, `fix:`), garantizando trazabilidad y claridad en el historial de cambios.
3. **Optimizacion de Rendimiento:** Empleo de carga diferida en imagenes (`loading="lazy"`), observadores asincronos sin bloqueo del event loop y minimizacion de recalculaciones de layout y repintados en el navegador.
4. **Diseno Responsivo y Mobile-First:** Experiencia visual fluida en dispositivos moviles, tablets y pantallas de escritorio mediante el uso calibrado de media queries, unidades relativas (`rem`, `ch`, `%`, `vh`, `vw`) y contenedores flexibles.
5. **Enfoque de Accesibilidad:** Implementacion de etiquetas semanticas de navegacion (`nav`, `main`, `section`, `article`, `aside`, `footer`), roles ARIA, gestion de atributos de accesibilidad dinamicos y soporte completo para navegacion mediante teclado.

## Instrucciones para Clonacion y Despliegue Local

Para inspeccionar o ejecutar este portafolio en un entorno de desarrollo local:

```bash
# 1. Clonar el repositorio oficial desde GitHub
git clone https://github.com/AaronBayas/Portafolio.git

# 2. Navegar al directorio del proyecto
cd Portafolio

# 3. Abrir con un servidor local estatico (o abrir index.html directamente en el navegador)
# Ejemplo con Python 3:
python -m http.server 8000

# Ejemplo con Node.js (npx serve):
npx serve .
```

Acceder desde el navegador en `http://localhost:8000`.
