## Perfil Profesional

Estudiante de octavo semestre de **Ingenieria en Software** en la **Universidad Estatal de Milagro (UNEMI)**. Especializado en desarrollo web full stack, arquitectura de software y diseno de interfaces centradas en la experiencia de usuario. Cuento con experiencia practica en el diseno y construccion de soluciones digitales integrales, abarcando desde el modelado de bases de datos relacionales y el consumo de APIs hasta el desarrollo de interfaces responsivas y accesibles.

Mi practica profesional se fundamenta en principios de ingenieria como Clean Code, diseno modular, estandares de accesibilidad WCAG y metodologias agiles de desarrollo.
